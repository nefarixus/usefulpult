# 🏠 Домашний пульт

Уютный тёмный виджет для рабочего стола Windows — часы, погода, курс
валют, список дел и генератор случайных слов в одном маленьком окошке,
которое всегда под рукой.

## ⬇️ Скачать

**[Последняя версия — вкладка Releases →](../../releases/latest)**

Два варианта на выбор:

- **`Домашний пульт Setup X.X.X.exe`** — обычный установщик. Ставится
  как любая программа, появляется в меню «Пуск», удаляется через
  «Установка и удаление программ».
- **`Домашний пульт X.X.X.exe`** — портативная версия. Ничего не
  устанавливает, просто запусти двойным кликом.

> ⚠️ При первом запуске Windows SmartScreen скорее всего покажет
> предупреждение «Windows защитила ваш компьютер» — это нормально для
> приложений без платной цифровой подписи. Нажми **«Подробнее» →
> «Выполнить в любом случае»**.

После установки приложение обновляется само — новые версии подхватываются
автоматически, скачивать вручную больше не нужно.

## ✨ Что внутри

- 🕐 **Часы** — свои + до двух дополнительных для других городов мира
- ⛅ **Погода** — с ручным выбором города, почасовым прогнозом и
  ощущаемой температурой
- 💱 **Курс валют** — конвертер на лету, без ключей и регистрации
- ✅ **Список дел** — с перетаскиванием пунктов для сортировки
- 🔤 **Генератор случайных слов** — клик по слову копирует его в буфер
- 🎨 **Темы** — 4 готовых цветовых пресета + свой цвет через палитру
- 🌍 **Русский и английский** интерфейс
- Автозапуск с Windows и иконка в трее — по желанию, включается в
  настройках
